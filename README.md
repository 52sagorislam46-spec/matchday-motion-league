# Matchday Motion League

আমি একটি ১১ বনাম ১১ ৩ডি ফুটবল গেম তৈরি করতে চাই। গেমের আগে দল নির্বাচন করার অপশন থাকবে, ৩ মিনিট বা ৬ মিনিট খেলার সময় নির্ধারণ করা যাবে। ৩ডি গ্রাফিক্স ও খেলোয়াড়দের অ্যানিমেশন (দৌড়ানো, পাস, শট, ট্যাকল) সহ ১১ জন বনাম ১১ জনের পূর্ণাঙ্গ ম্যাচ খেলার ব্যবস্থা থাকবে। অন-স্ক্রিন ও কিবোর্ড কন্ট্রোল, স্কোরবোর্ড, টাইমার এবং পরবর্তীতে রেফারি, ফাউল, কার্ড ও প্লেয়ার পরিবর্তনের উপযোগী আর্কিটেকচার থাকবে।
